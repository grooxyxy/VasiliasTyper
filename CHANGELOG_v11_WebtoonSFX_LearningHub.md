# VasiliasTyper — Webtoon SFX & Learning Hub

## Webtoon SFX Presets

- Menambahkan 28 preset SFX editable yang dikelompokkan sebagai Impact, Motion, Reaction, Quiet, dan Decorative.
- Menambahkan empat font komik open-source: Kalam Regular, Kalam Bold, Bangers, dan Permanent Marker.
- Menambahkan preview kata per preset; preview tidak pernah mengganti teks pengguna.
- Menambahkan metadata kategori dan petunjuk penggunaan pada daftar style.
- Fill, font, ukuran, bold, italic, outline, shadow, gradient, tracking, leading, dan alignment tetap dapat diedit melalui Text Studio.
- Menaikkan versi installer preset ke v2 agar koleksi baru otomatis tersedia bagi pengguna lama.
- Proses restore hanya mengganti preset bawaan bernama sama; style buatan pengguna tetap aman.

## Kompatibilitas

- Tidak mengubah format proyek, layer, atau elemen teks yang sudah ada.
- Field metadata style baru menggunakan nilai default dan tetap kompatibel dengan style lama.
- Tidak memerlukan koneksi internet untuk membuka artikel.

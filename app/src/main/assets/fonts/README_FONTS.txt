===================================================
  CARA MENAMBAH FONT KE FONT BANK VasiliasTyper
===================================================

Letakkan file .ttf atau .otf di folder ini:
  app/src/main/assets/fonts/

Contoh:
  app/src/main/assets/fonts/AnimeAce.ttf
  app/src/main/assets/fonts/WildWords.otf
  app/src/main/assets/fonts/CCMeanwhile.ttf

Setelah di-build ulang, font akan otomatis muncul
di Font Bank dengan nama file sebagai nama font.

Preset Webtoon SFX sudah membawa beberapa keluarga font agar
preview tidak terlihat seperti memakai satu font saja:
  - Bangers: impact/ledakan komik
  - Permanent Marker: brush/action
  - Kalam: tulisan tangan serbaguna
  - Rock Salt: kasar/gemetar
  - Gloria Hallelujah: kasual tidak seragam
  - Schoolbell: playful/repetitif
  - Coming Soon: tipis/reaksi kecil
  - Chewy: bulat/komik/outlined
  - Covered By Your Grace: tinggi dan cepat
  - Shadows Into Light Two: ringan/airy

Lisensi font yang dibundel tersedia di folder WebtoonSFX.
Font tambahan harus tetap bebas lisensi untuk penggunaan yang dituju.
